# QR Генератор + Чат

Одностраничное приложение на чистом HTML/CSS/JS: генератор QR-кодов и чат через Telegram-бота. Без сборки, без бэкенда — просто откройте `index.html`.

Приложение разделено на два раздела (переключатель вверху): **QR-код** и **Сообщения**.

## Раздел «QR-код»

- **7 типов QR-кодов**: ссылка, текст, Wi-Fi, e-mail, телефон, SMS, визитка (vCard)
- **Живая генерация** — код обновляется по мере ввода
- **Настройка**: цвет кода и фона, готовые схемы, уровень коррекции ошибок
- **Скачивание PNG** до 2048 px, копирование, «поделиться» (Web Share API / Telegram)

Всё генерируется локально в браузере.

## Раздел «Сообщения» (Андрей / Настя)

Чат двух пользователей через одного Telegram-бота. Настройки подключения (токен, Chat ID участников) — в отдельном сворачиваемом блоке «Настройки подключения»:

- Сообщение из веба уходит второму участнику в Telegram
- **Обратная связь**: всё, что написано боту в Telegram, появляется в ленте (опрос каждые 5 секунд)
- «Отправить QR сейчас» / автоотправка QR себе в Telegram (текст + картинка)

Настройка: @BotFather → `/newbot` → токен → оба участника пишут боту любое сообщение → «Узнать» у каждого.

## Вход по логину и паролю

Пользователи хранятся **в репозитории** — в файле [`users.js`](users.js). Сайт статический (GitHub Pages), поэтому «система» — это сам git: аккаунты Андрея и Насти уже заданы на любом устройстве, регистрация не нужна. При входе вводится логин и пароль — приложение само определяет, кто вошёл.

### Как создать/сменить пользователей

1. Скачайте репозиторий и откройте **`users-tool.html`** в браузере локально
2. Введите роль (Андрей/Настя), логин, имя и пароль — инструмент выдаст готовую строку с SHA-256 хешем и солью
3. Вставьте строку в `users.js` внутрь `window.QR_USERS = { ... }` вместо примера
4. Сделайте commit + push — новые учётные данные применятся на сайте

- Сессия живёт до закрытия вкладки; авто-выход после 10 минут простоя
- 5 неверных попыток → пауза 30 секунд

**Важно**: хеши лежат в открытом репозитории, и подбор по ним возможен офлайн — используйте длинные пароли (и приватный репозиторий, если он у вас есть). Проверка пароля выполняется в браузере, поэтому это защита интерфейса, а не серверная аутентификация.

## Запуск

Откройте `index.html` в любом браузере. Библиотека [qrcodejs](https://cdnjs.cloudflare.com/ajax/libs/qrcodejs/1.0.0/qrcode.min.js) подключается с CDN, поэтому нужен интернет.

## Публикация через GitHub Pages

1. Settings → Pages
2. Source: `Deploy from a branch`, ветка `main`, папка `/ (root)`
3. Save — сайт будет доступен по адресу `https://ashendilo-dev.github.io/qr-generator/`
