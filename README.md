# QR Генератор

Одностраничный генератор QR-кодов на чистом HTML/CSS/JS. Без сборки, без бэкенда — просто откройте `index.html`.

## Возможности

- **7 типов QR-кодов**: ссылка, текст, Wi-Fi, e-mail, телефон, SMS, визитка (vCard)
- **Живая генерация** — код обновляется по мере ввода
- **Настройка**: цвет кода и фона, готовые схемы, уровень коррекции ошибок
- **Скачивание PNG** в разрешении до 2048 px
- **Копирование** и **поделиться** (Web Share API / Telegram)
- **Автоотправка в Telegram или MAX** — содержимое QR улетает в мессенджер через вашего бота (см. ниже)
- Тёмная и светлая тема, адаптивная вёрстка

Всё генерируется локально в браузере; на сервер уходит только отправка через вашего собственного бота.

## Автоотправка QR в Telegram / MAX

Настройка (один раз, всё хранится в localStorage браузера):

1. Создайте бота:
   - **Telegram**: @BotFather → `/newbot` → скопируйте токен
   - **MAX**: создайте бота по инструкции [dev.max.ru](https://dev.max.ru) → скопируйте токен
2. Напишите своему боту любое сообщение (иначе он не сможет писать вам)
3. На сайте: блок «Чат через мессенджер» → выберите мессенджер, вставьте токен → «Узнать»
4. Включите «Отправлять QR автоматически» — теперь всё, что вы вводите, через пару секунд приходит в ваш чат с ботом

В Telegram приходят текст **и** картинка QR-кода, в MAX — текст.

## Запуск

Откройте `index.html` в любом браузере. Библиотека [qrcodejs](https://cdnjs.cloudflare.com/ajax/libs/qrcodejs/1.0.0/qrcode.min.js) подключается с CDN, поэтому нужен интернет.

## Чат через мессенджер (Андрей / Настя)

В блоке «Чат через мессенджер» два пользователя общаются через одного бота:

- **Роли**: «Кто я» — Андрей или Настя. Сообщение из веба уходит второму участнику в его мессенджер
- **Обратная связь**: всё, что написано боту в Telegram/MAX, появляется в ленте на странице (опрос каждые 5 секунд)
- **QR автоматически** уходит в чат текущего пользователя (если включить галочку)

Настройка: один общий бот → оба участника пишут ему любое сообщение → на странице «Узнать» для каждого.

### Защита данных

- **PIN-код** блокирует панель (SHA-256 + соль), авто-блокировка через 5 минут простоя, троттлинг подбора (5 попыток → пауза 30 с)
- Токен вводится в маскированное поле и хранится только в `localStorage` браузера
- История сообщений существует только в памяти страницы — закрыли вкладку, история исчезла
- Кнопка «Стереть все данные» удаляет токен, ID и PIN
- Апдейты не подтверждаются (без offset/marker), поэтому читать их может любой, кто знает токен — не публикуйте его

**Важно понимать границы**: это защита от случайных глаз на устройстве, а не шифрование — тексты проходят через серверы мессенджера и видны владельцу токена бота. Для по-настоящему секретного общения нужны E2E-мессенджеры.
