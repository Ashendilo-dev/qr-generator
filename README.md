# QR Генератор + Чат

Одностраничное приложение на чистом HTML/CSS/JS: генератор QR-кодов и чат через мессенджер-бота. Без сборки, без бэкенда — просто откройте `index.html`.

Приложение разделено на два раздела (переключатель вверху): **QR-код** и **Сообщения**.

## Раздел «QR-код»

- **7 типов QR-кодов**: ссылка, текст, Wi-Fi, e-mail, телефон, SMS, визитка (vCard)
- **Живая генерация** — код обновляется по мере ввода
- **Настройка**: цвет кода и фона, готовые схемы, уровень коррекции ошибок
- **Скачивание PNG** до 2048 px, копирование, «поделиться» (Web Share API / Telegram)

Всё генерируется локально в браузере.

## Раздел «Сообщения» (Андрей / Настя)

Чат двух пользователей через одного бота в Telegram или MAX:

- Сообщение из веба уходит второму участнику в его мессенджер
- **Обратная связь**: всё, что написано боту в Telegram/MAX, появляется в ленте (опрос каждые 5 секунд)
- «Отправить QR сейчас» / автоотправка QR себе в мессенджер

Настройка: один общий бот → оба участника пишут ему любое сообщение → «Узнать» для каждого. В Telegram приходят текст и картинка QR, в MAX — текст.

## Вход по логину и паролю

При первом открытии создаётся два аккаунта (Андрей и Настя, логины можно поменять). Дальше — экран входа: логин + пароль.

- Пароли хранятся как SHA-256 хеш со случайной солью, только в этом браузере
- Сессия живёт до закрытия вкладки; авто-выход после 10 минут простоя
- 5 неверных попыток → пауза 30 секунд
- «Забыли пароль?» = полный сброс (восстановления нет — это статическая страница без сервера)

**Границы защиты**: это клиентская авторизация — она закрывает интерфейс от посторонних на устройстве, но не заменяет серверную. Не публикуйте токен бота: тот, кто его знает, может читать сообщения боту.

## Запуск

Откройте `index.html` в любом браузере. Библиотека [qrcodejs](https://cdnjs.cloudflare.com/ajax/libs/qrcodejs/1.0.0/qrcode.min.js) подключается с CDN, поэтому нужен интернет.
